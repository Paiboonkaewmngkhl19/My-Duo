# myAIS Duo Smart Package Builder

Interactive prototype of a package builder for the iPhone Duo foldable. The app is `index.html` plus the logo in `assets/`, so there is no build step.

The switcher in the toolbar opens all four views: Folded Portrait, Folded Landscape, Unfolded Portrait and Unfolded Landscape.

To run it locally, use `npm run dev` and open `http://localhost:8000`.

To deploy, enable GitHub Pages for the `main` branch, root folder.

All prices are illustrative prototype data.
